# Primeira semana

## Objetivos

1. Entregar um PR feito inteiramente no Dev Spaces.
2. Entender o [devfile](../uso/devfile.md) do repositório do time.
3. Conhecer as [boas práticas](../uso/boas-praticas.md) de uso de recursos.

## Atividades sugeridas

| Dia | Atividade |
|-----|-----------|
| 2 | Pareamento com o buddy numa tarefa real, os dois no mesmo repositório |
| 3 | Ler o `devfile.yaml` com o tech lead: componentes, comandos e endpoints |
| 4 | Propor uma melhoria no devfile (um comando novo, uma extensão recomendada) |
| 5 | Abrir o PR, passar pelo CI e fazer o merge |

## Checklist

- [ ] PR aberto e aprovado, feito no Dev Spaces
- [ ] Sei explicar os componentes do devfile do time
- [ ] Sei expor uma porta e abrir a aplicação
- [ ] Configurei as extensões recomendadas (`.vscode/extensions.json`)
- [ ] Sei onde pedir ajuda ([Problemas comuns](../problemas-comuns.md))

!!! success "Pronto!"
    Você concluiu o onboarding do Dev Spaces. Ajude a melhorar este guia pelo ícone de edição no
    topo da página.
