# Manual de Podman Desktop

O **Podman** executa containers sem daemon e sem root. O **Podman Desktop** é a interface
gráfica para gerenciar containers, imagens, pods e a *Podman machine*.

!!! note "Windows"
    No Windows, o Podman roda dentro de uma VM no WSL 2. Instale o WSL antes
    ([Manual de WSL](http://localhost:3000/docs/default/component/manual-wsl)).
