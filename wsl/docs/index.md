# Manual de WSL

O **Windows Subsystem for Linux (WSL)** executa distribuições Linux dentro do Windows, com
kernel Linux real (WSL 2). É o ambiente padrão de desenvolvimento em estações Windows.

## Requisitos

- Windows 10 22H2 ou Windows 11.
- Virtualização habilitada na BIOS/UEFI.
- Permissão de administrador local (ou instalação pelo catálogo de software corporativo).
